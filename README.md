# CAD Automation Pipeline

Python-based STEP geometry analyzer and parametric 
build123d reconstruction tool built for mechanical 
component reconstruction.

## What it does
- Analyzes STEP files using OpenCascade (OCP)
- Extracts exact B-Rep dimensions, bounding boxes, 
  face types, planar profiles
- Generates parametric CSG reconstruction scripts
- Validates geometry using symmetric difference
- Outputs HTML, JSON, CSV reports per part

## Tools Used
Python, build123d, OpenCascade (OCP), SolidWorks
